# Техническая спецификация: «Живой трекер» (Living Tracker)

## 1. Утверждённый стек технологий

### Десктоп-оболочка и система
- **Основа:** Tauri 2.0 (Rust)
  - Потребление RAM: ~35–50 МБ (системный WebView2 на Windows).
  - Вес сборки: ~12–15 МБ.
  - Плагины Tauri:
    - `tauri-plugin-sql` (SQLite хранилище с миграциями).
    - `tauri-plugin-autostart` (автозапуск при старте Windows).
    - `tauri-plugin-global-shortcut` (глобальный хоткей для вызова HUD-виджета, напр. `Ctrl+Space`).
    - `tauri-plugin-notification` (системные уведомления).
  - Режим окон:
    - Главное окно: полноразмерный командный центр (кастомизируемый дашборд).
    - Окно-виджет: безрамочное (`decorations: false`), плавающее поверх всех окон (`alwaysOnTop: true`), полупрозрачное, с возможностью сворачивания в трей.

### Фронтенд и интерфейс
- **Ядро:** React 19 + TypeScript + Vite.
- **Стилизация:** Tailwind CSS 4.0.
- **Анимации и «вкусный» UI (Juiciness):**
  - `framer-motion` (плавное наливание и пульсация круга бюджета, всплывающие окна ачивок, перетаскивание карточек).
  - `canvas-confetti` (салюты и частицы при выполнении целей и получении редких ачивок).
- **Стейт-менеджмент:** Zustand (легковесные модульные сторы + шина событий).
- **Интернационализация (i18n):** `react-i18next` (Русский язык — основной, Английский — вторичный).

### Локальные данные и надежность
- **База данных:** SQLite (локальный файл в `%APPDATA%/living-tracker/data.db`).
- **Схема слоя БД:** абстракция Repository (в браузере при разработке работает IndexedDB/LocalStorage, в Tauri — нативный SQLite).
- **P2P задел (Синхронизация):** CRDT через `Yjs` + `y-webrtc` (синхронизация между своими устройствами без центрального сервера персональных данных).

### Графика и Шеринг
- **Генерация карточек ачивок:** `html2canvas` (рендер карточки 1080x1080 в PNG прямо в буфер обмена).
- **Иконки:** Lucide React + локальный каталог пользовательских SVG/PNG иконок.

---

## 2. Архитектура расширяемости (Плагины и Маркетплейс)

- **UI Slots:** Точки встраивания в главном окне (`dashboard.widgets`, `sidebar.nav`, `task.actions`).
- **Event Bus:** Шина событий `eventBus.emit(event)` / `eventBus.on(event, handler)`, связывающая любые действия пользователя с проверкой ачивок и реакциями плагинов.
- **Каталог дополнений:** Загрузка манифестов из локальной папки плагинов `%APPDATA%/living-tracker/plugins/` с возможностью отключения тумблером в настройках.

---

## 3. Тоны текстов ачивок и системных сообщений

Каждое достижение и оповещение имеет 3 варианта:
1. `neutral` — сдержанный, классический тон.
2. `ironic` — с сарказмом и иронией.
3. `sassy` — дерзкий, неформальный, с крепким юмором и матом (для себя и близких).
